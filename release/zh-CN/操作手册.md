# CS2 自拍杆 DLL 操作手册

v0.4.5 正式发布版：人物相机绑定探员骨架上的 `weapon_hand_r` 右手附件，枪械/刀不再提供主锚点；眼位读取已修正为当前验证的虚表第 173 槽。手部附件暂时不可用时沿用短期人物局部位置，再使用身体相对位置。首次从旧构图迁移时备份配置为 `selfiestick.ini.pre-hand-anchor.bak`，升级到 `FramingVersion=6` 并重置人物微调，道具参数保留。仅做了后台验证，尚未进入 demo 实测，未实现地图碰撞避让。

## 发布目录内容

中文发布目录包含：

- `Lyan_CS2自拍杆.dll`
- `操作手册.md`
- `selfiestick_bind.cfg`

实际运行只需要 DLL。手册和 cfg 是说明文件。

DLL 已静态链接 MSVC 运行库，用户不需要额外安装 Visual C++ Redistributable 就可以通过 HLAE 加载。

## 支持版本

当前发布包标记支持：

- HLAE：`2.192.10`（AfxHookSource2 `0.41.9`）
- Counter-Strike 2：Steam app `730`，buildid `26445667`

CS2 和 HLAE 经常更新。如果后续游戏 schema、实体布局或 `SetUpView` 变化，DLL 可能会主动阻塞，并在面板里显示原因。

## 加载 DLL

1. 把整个 `zh-CN` 文件夹复制到稳定位置。
2. 启动 HLAE `2.192.10`，进入 CS2，并打开 demo 观战。
3. 在 HLAE 控制台执行：

```cfg
mirv_loadlibrary "<Lyan_CS2自拍杆.dll 的绝对路径>"
```

示例：

```cfg
mirv_loadlibrary "D:\tools\selfiestick\zh-CN\Lyan_CS2自拍杆.dll"
```

加载成功后，按 `Ins` 打开真正的 Dear ImGui 面板。自定义 CPU/GDI 软件后端不会创建 D3D11 设备、DXGI 交换链、OpenGL 上下文或调用 Present，因此可以和 ReShade 一起注入。每一帧都会先在离屏缓冲区完整绘制，再复制到窗口，不会再出现原生滑轨拖影/涂抹。

如果 HLAE 提示 `mirv_loadlibrary failed`，请先完整重启 HLAE/CS2，并确认绝对路径正确。当前 release DLL 不再依赖 `MSVCP140.dll`、`VCRUNTIME140.dll`、UCRT `api-ms-win-crt-*` DLL，也不再依赖任何 `D3DCOMPILER_*.dll`。

当前 release DLL 不会在启动阶段主动执行重 schema 解析，也不会在 `mirv_loadlibrary` 加载瞬间安装 SetUpView 相机热补丁。热补丁只会在按 `F8` 或点击启用自拍杆时安装；如果 HLAE 2.192.10 / AfxHookSource2 0.41.9 已先改写同一位点，DLL 会先串接 HLAE 的 trampoline，再执行自拍杆回调。如果当前 CS2 版本不兼容，DLL 会保持加载并在 Runtime 区域显示原因，而不是直接拖崩 demo 进程。发布包里的 `selfiestick.ini` 默认关闭调试日志；只有需要发诊断日志时，才建议手动设置 `[Debug] TraceEnabled=1`。

如果 DLL 同目录已经有旧版生成的 `selfiestick.ini`，测试新版前请删除它，或确认 `[Debug] TraceEnabled=0`。

当前 v0.4.5 DLL 不再导入 `d3d11.dll` 或 `dxgi.dll`。如果新转储仍经过 ReShade 提供的 `dxgi.dll`，先核对加载的 DLL 是否确实为 v0.4.5，再单独排查其它图形注入器。

推荐设置速度：道具自拍调机位时，建议先通过 CS2 demo UI / HLAE 播放控制把 demo 降到 `0.1x` 倍速；如果当前游戏控制台可用，也可以执行：

```cfg
demo_timescale 0.1
```

## 热键

面板使用 Dear ImGui 官方 Dark 风格。十二个位置/角度参数均有标准滑块与数值框，数值框按钮以 `0.25` 步进调整。底部“运行状态”使用标准折叠栏。人物默认从武器前侧回看探员上半身中心；可点击“居中人物自拍”恢复零微调。不要沿用已加载的旧 DLL，替换文件后需要完整重启 HLAE/CS2。

- `Ins`：默认显示 / 隐藏面板
- `F8`：启用 / 关闭自拍杆
- `F9`：锁定当前观战目标
- `F10`：目标模式回到跟随

面板开关键可以在面板里修改，并保存到 DLL 同目录的 `selfiestick.ini`。

## 人物自拍模式

在 `相机模式` 里选择 `人物自拍`，使用原来的人物自拍杆。

主要控制：

- `左侧自拍`：从目标左侧构图自拍
- `右侧自拍`：从目标右侧构图自拍
- `越肩视角`：相机位于枪械右后侧，探员保留在画面左侧前景
- `应用越肩视角预设`：切到人物自拍、清空额外微调并应用内置越肩构图
- `跟随`：每帧使用当前观战目标
- `锁定当前`：锁定当前目标探员
- `清除锁定`：清除目标锁定
- `人物 右 / 后 / 上`：通过原生数字输入框或 0.25 步进滑轨调整人物相机位置
- `人物 俯仰 / 偏航 / 翻滚`：通过原生数字输入框或滑轨调整人物相机角度

默认人物自拍从探员右手骨架附件的前侧回看上半身中心，构图不再依赖枪械/刀实体。`居中人物自拍` 可清除人物微调；`FramingVersion=6` 首次迁移会保留旧 INI 备份并重置原来的枪口相对人物微调，道具参数不变。左右构图保持镜像对称，人物 `右 / 后 / 上` 和 `俯仰 / 偏航 / 翻滚` 均为内置构图之外的额外微调。

## 道具自拍模式

在 `相机模式` 里选择 `道具自拍`，相机会跟随当前目标探员投出的飞行道具。

推荐工作流：先把 demo 播放速度调到 `0.1x`，再跟随或锁定目标探员；等道具候选出现后，单个道具会自动锁定，多个道具则在 `最近道具` 中手动点 `锁定`；之后调 `X / Y / Z` 和 `俯仰 / 偏航 / 翻滚`。构图稳定后，再按需要提高 demo 速度。

支持道具：

- 烟
- 火，包含 molotov / incendiary
- 雷
- 闪
- 诱饵

行为规则：

- 目标探员仍然由 `跟随 / 锁定当前` 决定。
- 只接受当前目标探员 pawn 或 controller 拥有 / 投出的飞行道具。
- 如果当前只有 1 个有效飞行道具，并且没有锁定道具，会自动锁定。
- 如果同时有多个有效飞行道具，不会自动抢锁，需要在 `最近道具` 中手动点 `锁定`。
- `清除道具` 会清除当前道具锁定。如果下一帧仍然只有 1 个有效道具，可以再次自动锁定。
- 道具相机会缓存投掷初速度的反向水平偏航，不再随投掷者后续位置漂移，同时保持画面地平线稳定，避免普通高抛道具出现过高/过低的异常视角。
- 未锁定时会约以 30 Hz 优先检查最新实体区，使飞行时间很短的道具不必等待整轮扫描结束。
- 闪光、HE、燃烧和诱饵飞行实体消失后会保留最后有效镜头 0.45 秒；烟雾保留 1.2 秒。
- 相机载体继续使用平滑预测锚点，但镜头永远瞄准道具当前的真实原点，高速飞行时也不会因预测超前而偏离屏幕中心。
- 跟踪会把道具的 schema 真实速度方向与实测移动速率结合，因此慢放和正常播放都使用正确的预测速度；播放暂停时停止外推，弹跳计数变化时重置预测，字段不可用时仍会安全回退到位置差分估速。
- 道具发现按固定批次分摊；在受支持版本上，已锁定道具优先走场景节点原点快路径，避免每次相机回调都执行完整的动态原点搜索。

道具控制：

- `道具 X / Y / Z`：通过原生数字输入框或 0.25 步进滑轨调整道具相机局部偏移
- `俯仰 / 偏航 / 翻滚`：通过原生数字输入框或滑轨调整角度
- `居中回看预设`：把相机放到道具出手轨迹轴正前方：`X=0`、`Y=-13.5`、`Z=2.25`、`俯仰=0`、`偏航=0`、`翻滚=0`
- `最近道具`：显示候选道具、是否飞行中、句柄、投掷者句柄、帧龄、类型和锁定按钮

道具相机使用平滑预测锚点，减少慢放和正常速度下的一跳一跳、上下抽搐和卡顿感。

## 状态与排错

底部“运行状态”是默认收起的诊断栏，点击即可展开，再次点击收起。展开后会显示：

- 启用状态
- 相机模式
- 朝向
- 面板按键
- 目标模式
- 锁定目标 / 当前目标
- 道具锁定与候选
- 最近覆写结果
- 失败原因

调试日志默认关闭。需要排查问题时，可以在 DLL 同目录的 `selfiestick.ini` 里设置：

```ini
[Debug]
TraceEnabled=1
```

完整重启 HLAE/CS2 后，日志会写在加载 DLL 的同目录：

```text
selfiestick_trace.log
```

如果替换 DLL 后仍加载旧版本，请完整重启 HLAE 和 CS2。Windows 会把已加载 DLL 保留在进程里，单纯覆盖文件不一定会立即生效。

## 安全说明

本 DLL 只用于 HLAE demo / 影视工作流，不用于匹配、实战或任何反作弊保护服务器。使用 HLAE 或注入工具进入 VAC 服务器存在风险。

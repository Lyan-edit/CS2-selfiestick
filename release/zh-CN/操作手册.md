# CS2 自拍杆 DLL 操作手册

本版适配 CS2 1.41.9.7 / build 26598758：核验 32 个 schema 字段并将人物朝向改为 0x3630，重定位人物末尾回调、绝对坐标接口、实体生命周期和 Demo 时钟。人物／道具相机算法沿用 0.4.7。

当前正式版为 `v0.4.8`，包含 player-final-view-fix4 人物修正。人物相机改为探员身体的固定局部机位；手部骨骼、枪械和动画眼位不再驱动相机，移动、转身和下蹲仍正常跟随。人物坐标先经引擎重算，下蹲高度读取精确版本核验的移动服务字段；场景暂缺时保留已验证的机位、FOV 和模型状态。慢放时只对人物局部偏航做短时过渡，身体原点与距离保护保持原样，暂停停止推进。人物诊断导出 selfiestick_player_motion.csv，含原始／处理后偏航和 Demo 倍率。首次从旧构图迁移时备份配置为 `selfiestick.ini.pre-hand-anchor.bak`，升级到 `FramingVersion=6` 并重置人物微调，道具参数保留。fix5 道具坐标修复已由用户实测确认无抖动，0.4.7 保留该实现；新版机位生命周期仅完成后台验证，未实现地图碰撞避让。

v0.4.8 将人物覆写移至当前精确游戏版本的原生 SetUpView 最后阶段，避免之前的机位被后续原生位置／角度／FOV 处理覆盖；道具仍使用原回调路径。人物 FOV 在每次启用或目标变化时捕获并保持，跨回调线程共享，切枪／切刀不会重新取值；需要采用新的 HLAE FOV 时关闭再开启人物自拍。人物诊断现为 34 列，新增原生输入 FOV、线程 ID、早期／末尾回调阶段，便于区分输入抖动和后续覆盖。升级需完整重启 HLAE/CS2，加载一个新版 DLL。

## 发布目录内容

中文发布目录包含：

- `Lyan_CS2自拍杆.dll`
- `操作手册.md`
- `selfiestick_bind.cfg`

实际运行只需要 DLL。手册和 cfg 是说明文件。

DLL 已静态链接 MSVC 运行库，用户不需要额外安装 Visual C++ Redistributable 就可以通过 HLAE 加载。

## 支持版本

当前发布包目标版本（HLAE 2.193.0 已静态核查；本次未做实机 Demo 验证）：

- HLAE：`2.193.0`（AfxHookSource2 `0.42.0`）
- Counter-Strike 2：Steam app `730`，buildid `26598758`

CS2 和 HLAE 经常更新。如果后续游戏 schema、实体布局或 `SetUpView` 变化，DLL 可能会主动阻塞，并在面板里显示原因。

## 加载 DLL

1. 把整个 `zh-CN` 文件夹复制到稳定位置。
2. 启动 HLAE `2.193.0`，进入 CS2，并打开 demo 观战。
3. 在 HLAE 控制台执行：

```cfg
mirv_loadlibrary "<Lyan_CS2自拍杆.dll 的绝对路径>"
```

示例：

```cfg
mirv_loadlibrary "D:\tools\selfiestick\zh-CN\Lyan_CS2自拍杆.dll"
```

加载成功后，按 `Ins` 打开真正的 Dear ImGui 面板。自定义 CPU/GDI 软件后端不会创建 D3D11 设备、DXGI 交换链、OpenGL 上下文或调用 Present，因此可以和 ReShade 一起注入。每一帧都会先在离屏缓冲区完整绘制，再复制到窗口，不会再出现原生滑轨拖影/涂抹。

如果 HLAE 提示 `mirv_loadlibrary failed`，请先完整重启 HLAE/CS2，并确认绝对路径正确。当前 release DLL 不再依赖 `MSVCP140.dll`、`VCRUNTIME140.dll`、UCRT `api-ms-win-crt-*` DLL，也不再依赖任何 `D3DCOMPILER_*.dll`。

当前 release DLL 不会在启动阶段主动执行重 schema 解析，也不会在 `mirv_loadlibrary` 加载瞬间安装 SetUpView 相机热补丁。热补丁只会在按 `F8` 或点击启用自拍杆时安装；如果 HLAE 2.193.0 / AfxHookSource2 0.42.0 已先改写同一位点，DLL 会先串接 HLAE 的 trampoline，再执行自拍杆回调。如果当前 CS2 版本不兼容，DLL 会保持加载并在 Runtime 区域显示原因，而不是直接拖崩 demo 进程。发布包里的 `selfiestick.ini` 默认关闭调试日志；只有需要发诊断日志时，才建议手动设置 `[Debug] TraceEnabled=1`。

如果 DLL 同目录已经有旧版生成的 `selfiestick.ini`，测试新版前请删除它，或确认 `[Debug] TraceEnabled=0`。

当前 v0.4.8 DLL 不再导入 `d3d11.dll` 或 `dxgi.dll`。如果新转储仍经过 ReShade 提供的 `dxgi.dll`，先核对加载的 DLL 是否确实为 v0.4.8，再单独排查其它图形注入器。

推荐设置速度：道具自拍调机位时，建议先通过 CS2 demo UI / HLAE 播放控制把 demo 降到 `0.1x` 倍速；如果当前游戏控制台可用，也可以执行：

```cfg
demo_timescale 0.1
```

## 热键

面板使用 Dear ImGui 官方 Dark 风格。十二个位置/角度参数均有标准滑块与数值框，数值框按钮以 `0.25` 步进调整。底部“运行状态”使用标准折叠栏。人物默认从武器前侧回看探员上半身中心；可点击“居中人物自拍”恢复零微调。不要沿用已加载的旧 DLL，替换文件后需要完整重启 HLAE/CS2。

- `Ins`：默认显示 / 隐藏面板
- `F8`：启用 / 关闭自拍杆
- `F9`：锁定当前观战目标
- `F10`：目标模式回到跟随

面板开关键可以在面板里修改，并保存到 DLL 同目录的 `selfiestick.ini`。

## 人物自拍模式

在 `相机模式` 里选择 `人物自拍`，使用原来的人物自拍杆。

主要控制：

- `左侧自拍`：从目标左侧构图自拍
- `右侧自拍`：从目标右侧构图自拍
- `越肩视角`：相机位于枪械右后侧，探员保留在画面左侧前景
- `应用越肩视角预设`：切到人物自拍、清空额外微调并应用内置越肩构图
- `跟随`：每帧使用当前观战目标
- `锁定当前`：锁定当前目标探员
- `清除锁定`：清除目标锁定
- `人物 右 / 后 / 上`：通过原生数字输入框或 0.25 步进滑轨调整人物相机位置
- `人物 俯仰 / 偏航 / 翻滚`：通过原生数字输入框或滑轨调整人物相机角度

默认人物自拍从探员身体固定机位的前侧回看上半身中心，构图不再依赖枪械/刀实体。`居中人物自拍` 可清除人物微调；`FramingVersion=6` 首次迁移会保留旧 INI 备份并重置原来的枪口相对人物微调，道具参数不变。左右构图保持镜像对称，人物 `右 / 后 / 上` 和 `俯仰 / 偏航 / 翻滚` 均为内置构图之外的额外微调。

## 道具自拍模式

在 `相机模式` 里选择 `道具自拍`，相机会跟随当前目标探员投出的飞行道具。

推荐工作流：投掷前启用 `道具自拍`，跟随或锁定目标探员；新投掷的道具会自动捕获，需要固定某一颗时在 `最近道具` 中手动点 `锁定`。之后调 `X / Y / Z` 和 `俯仰 / 偏航 / 翻滚`。调机位时建议使用 `0.1x`，构图稳定后再提高播放速度。

支持道具：

- 烟
- 火，包含 molotov / incendiary
- 雷
- 闪
- 诱饵

行为规则：

- 目标探员仍然由 `跟随 / 锁定当前` 决定。
- 只接受当前目标探员 pawn 或 controller 拥有 / 投出的飞行道具。
- 当前正式版为 `v0.4.8`，保留用户确认无抖动的 fix5 坐标和构图实现。没有手动锁定时，按投掷生成时间和持续保留的可跟随顺序捕获新道具；归属信息延迟超过 0.1 秒也可以接管旧自动镜头。
- `自动接续`：跟随到实际爆开，最终机位保持 **Demo 时间 2 秒**，之后返回当前探员主视角，继续等待下一次投掷。慢放会延长现实停留时间，暂停时计时停止；新道具可以立即接管，无需等满 2 秒。
- `锁定当前道具`：跟随当前这一颗直至爆开，之后无限保留最终视角，不受下一颗影响。最近道具列表的 `选中并锁定` 则切换到指定的有效道具，再使用相同锁定规则；无有效机位缓存的已结束道具不能重新选取。
- 再次选择 `自动接续` 即取消锁定、恢复接续；已有新道具时立即接管，否则爆开后已满 2 秒就返回探员。
- `清除锁定并返回探员`：立即释放镜头，返回当前探员主视角，避免下一帧被同一颗或已存在的候选再次抓回；后续新出手仍会自动捕获。下方“跟随目标”中的 `清除锁定` 同时释放道具镜头和探员目标锁定，恢复跟随当前探员。显式点击列表仍可重新选择有效候选。
- 道具相机会锁存第一次有效投掷初速度的反向水平偏航；临时方向在初速度到达后只升级一次，后续数据变化或弹跳不会重建已确定的方向，保持地平线稳定。
- 道具创建通知优先捕获，保留原有游戏/HLAE 调用链；每次回调处理最多 64 条通知。已核验的接口实际返回实体数量，不能代表最大槽号，因此后台扫描覆盖完整 `0..32767` 范围，按约 0.5 毫秒软预算分摊，不再漏掉数量范围之外的稀疏高槽位。通知安装不可用时继续使用完整扫描。
- 已知和待初始化的道具槽最多 128 个，每次回调优先复查，不等待后台扫描走到该槽。共享基础 RTTI 时，使用与 HLAE 一致的 `m_designerName` 识别具体道具类型。
- 新实体有 0.1 秒初速度宽限，较新生成时间和实际位置变化也能补充飞行判断；接管资格不再随该宽限过期。启用时已经落地的旧烟雾和诱饵不会仅凭旧初速度占据镜头。
- 落地、停止移动和预定起爆 tick 不再被当成结束。确认实际效果标志或实体移除后，镜头停留在最后有效的爆开位置；游戏继续播放，烟雾、火焰等效果正常发展。自动模式下这种停留不会阻挡新道具。
- 短暂坐标/归属缺失时保留有效机位并持续尝试恢复，避免清锁后闪回观战。下一颗尚无有效坐标时，也先保留上一画面，准备好后再接管。每颗道具锁存自己的 FOV，减少观战缩放造成的闪动。
- 忽略一 tick 的模拟时间抖动；回退超过 0.25 秒会重置投掷顺序。清除按钮用于释放视角，保留投掷顺序；需要重播时回退到出手之前。
- 相机直接绑定当前渲染场景节点原点，位置与瞄准使用同一次采样；相对道具的直线距离恒为 `sqrt(X² + Y² + Z²)`。不再积分独立镜头速度，因此不会因倍速、帧率、暂停或重复网络数据逐渐拉远。
- 旧配置 `PropFollowSpeed` 保留兼容，但不再限制跟随速度，也不需要提高它来追上道具。
- 通过游戏自身的绝对坐标接口先处理待重算的场景变换，再取坐标；不再直接使用可能过期的字段缓存。缺失时仍保留有效机位，不猜测任意内存向量。若道具完全处于两次可见相机帧之间，仍需慢放。

道具控制：

- `道具 X / Y / Z`：通过原生数字输入框或 0.25 步进滑轨调整道具相机局部偏移
- `俯仰 / 偏航 / 翻滚`：通过原生数字输入框或滑轨调整角度
- `居中回看预设`：把相机放到道具出手轨迹轴正前方：`X=0`、`Y=-13.5`、`Z=2.25`、`俯仰=0`、`偏航=0`、`翻滚=0`
- `最近道具`：显示候选道具、是否飞行中、句柄、投掷者句柄、帧龄、类型和锁定按钮

道具跟随沿用游戏场景节点的当前运动，镜头不额外预测或积分位置。完整重启 HLAE/CS2 后只加载一个新版 DLL，投掷前启用道具自拍，以便提前接收创建通知。

## 状态与排错

同一机位内仍出现道具/背景抖动时，展开 `运行状态`，点击 `导出抖动诊断`。会在加载的 DLL 同目录生成 `selfiestick_prop_motion.csv`，包含版本、最近最多 1,024 次镜头采样的坐标、句柄、阶段和 FOV。正常跟随只写内存缓冲，点击导出才由后台线程写文件；不用为此开启逐帧日志。若要继续定位，保留抖动刚发生后导出的文件即可。

底部“运行状态”是默认收起的诊断栏，点击即可展开，再次点击收起。展开后会显示：

- 启用状态
- 相机模式
- 朝向
- 面板按键
- 目标模式
- 锁定目标 / 当前目标
- 道具锁定与候选
- 最近覆写结果
- 失败原因

调试日志默认关闭。需要排查问题时，可以在 DLL 同目录的 `selfiestick.ini` 里设置：

```ini
[Debug]
TraceEnabled=1
```

完整重启 HLAE/CS2 后，日志会写在加载 DLL 的同目录：

```text
selfiestick_trace.log
```

如果替换 DLL 后仍加载旧版本，请完整重启 HLAE 和 CS2。Windows 会把已加载 DLL 保留在进程里，单纯覆盖文件不一定会立即生效。

## 安全说明

本 DLL 只用于 HLAE demo / 影视工作流，不用于匹配、实战或任何反作弊保护服务器。使用 HLAE 或注入工具进入 VAC 服务器存在风险。

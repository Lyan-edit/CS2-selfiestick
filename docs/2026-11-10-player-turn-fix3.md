本地构建 `v0.4.6 player-turn-fix3`，适配 CS2 build `26445667` / HLAE `2.192.10`。
GitHub 已发布的 v0.4.6 附件未替换。

## 已确认的基线

用户实测反馈：body-fix2 已不再穿模，但 **0.1 倍速或更慢的转身、开枪仍有轻微抽搐**。
修改前已将完整工作源码、中英文 DLL、身体函数与道具文件校验清单保存至：

`dist/checkpoints/2026-11-10-body-fix2-user-confirmed-no-clipping/`

本次身体原点／下蹲高度函数、身体距离保护函数与该检查点逐项哈希一致；五个 `prop_*.inl` 文件逐字节一致。没有对世界位置做独立速度积分或延迟跟随。

## 定位范围

body-fix2 的局部机位已经脱离手臂与动画眼位，但偏航仍直接使用 `m_angEyeAngles`。当该输入离散更新时，慢放会拉长每次变化的现实时间，固定距离的相机仍可能沿探员周围发生微小阶梯转向。

新增生产人物构图用例输入量化偏航：64 个源 tick/秒，每次源偏航变化 1°。未接入处理时，0.01x / 30 FPS 用例记录最大单帧变化 **1.000°** 并失败。它说明该路径没有抑制离散转向；本次没有收到实机人物 CSV，因此不能将实机残余抖动的全部来源直接归因于该输入。

## 修改

- **只处理人物局部偏航**。身体原点、下蹲高度、相对机位半径和既有距离保护继续使用 body-fix2 逻辑。人物仍保持居中瞄准，R/B/U 和额外角度微调不经过这个滤波器。
- 使用最短角差，跨越 +180° / -180° 不会反方向绕一圈。偏航采用指数过渡，时间常数为 **0.012 秒 Demo 时间**；会引入少量转向滞后，不是零延迟。
- 通过 Demo tick 与单调墙钟的完整 tick 间隔估计播放倍率，保留最近 8 个间隔。估计速率用于每个相机回调的连续推进，避免输出仍按整数 tick 跳动。启用或切换倍率后需要新的完整 tick 间隔建立／更新估计。
- 读取已核验的 `IDemoFile::IsDemoPaused`，暂停期间保持偏航；恢复播放不累计暂停的墙钟时长。暂停时显式跳转、时间回退、较大前跳、目标句柄／实体系统变化和启用代次变化会重新建立状态。
- 不可信或不可用的 Demo 时钟会停用偏航处理，使用原偏航，不以未知墙钟倍率代替。诊断字段 `turn_filtered=0` 可识别这种情况。
- 新时钟读函数复用当前精确 engine2 指纹和 HLAE 接口布局，逐次验证方法地址；只缓存 engine 接口，不缓存可能随 Demo 改变的 player 对象。没有新增 Hook 或运行时 schema 探测。

暂停方法已独立从安装版 engine2 的主 RTTI／vtable 核实：槽 12，RVA `0x35A40`，函数体为只读暂停查询。`tools/check_prop_demo_clock.py` 同时检查原有槽 69/3 和新暂停查询；原道具时钟文件未改动。

## 诊断导出

人物模式“运行状态→导出抖动诊断”仍写入 DLL 同目录的 `selfiestick_player_motion.csv`。当前为 **31 列**，在原 25 列之后增加：

- `yaw_input` / `yaw_output`：原始与处理后的偏航。
- `estimated_demo_rate`：tick 间隔估计的倍率。
- `demo_tick` / `demo_paused` / `turn_filtered`：时钟与处理状态。

数值跨 ±180° 时应按最短角差比较。CSV 记录本 DLL 回调的状态，不是 GPU 最终画面，也不能直接观测其它插件后续改写。

## 后台检查

- 中英文生产函数测试覆盖 **0.01/0.1/1/8 倍速 × 30/60/144/500 FPS**，相机仍跟随当前身体位置，局部距离不变。
- 0.1x / 144 FPS 的人工 1° 源 tick 输入：最大输出单帧变化 **0.0777°**，约降低 92%；最大偏航滞后 **1.304°**。该数据来自可重复后台用例，不是实机抖动测量。
- 人工每回调交替 ±0.2° 的偏航扰动：稳定后最大残余约 **0.0058°**。这不是对真实开枪噪声幅度的断言。
- 最短角度跨界、暂停不漂移、恢复、重复子视角回调、跳转重置、目标句柄变化、启用代次变化及无时钟回退通过。
- 新增 300 次完整 SetUpView 转向／扰动回调，继续满足身体间距；原有 1,200 次完整回调、480 个脏坐标、600 次有效动画脱钩及道具回归通过。
- 人物 CSV 独立解析：每版 1,024 行、31 列、序号严格递增，含成功／失败状态及至少 300 条处理已启用的输入／输出／倍率样本。
- 当前 client 的 32 个 schema 字段、相关特征码、眼位和绝对坐标访问器通过。原生验证、PowerShell 7 中英文 x64 `/MT` 构建、两版依赖和 ImGui framebuffer 检查通过。
- fix5 的 12 个受保护区段，以及 body-fix2 已确认的身体高度／距离保护函数均保持一致。

没有启动、注入或前台操作 CS2，也没有本次实机 Demo、ReShade 共存或实际 FPS 测量。需实机确认剩余轻微抽搐是否消除。

## Reproduction and primary evidence

The existing checks were run before any edit against the newly installed game:

```powershell
python tools/check_cs2_binary_compatibility.py --client <game/csgo/bin/win64/client.dll> --schema <game/bin/win64/schemasystem.dll>
python tools/check_player_final_view.py --client <game/csgo/bin/win64/client.dll>
python tools/check_prop_demo_clock.py --engine <game/bin/win64/engine2.dll>
```

All three failed with v0.4.7 data: client fingerprint mismatch, `m_angEyeAngles` expected 0x3600 versus actual 0x3630, moved lifecycle targets, invalid old origin accessor, and engine clock fingerprint mismatch. These are deterministic offline compatibility failures, not a claimed live-demo crash reproduction.

The same three checks pass with v0.4.8. Static PE schema tables, primary RTTI/vtables, `.pdata` function bounds and actual machine instructions were used to relocate targets. Existing wildcard signatures still match the intended new-build sites; their strings did not need modification.

All 32 consumed schema fields were verified; only the eye-angle offset changed among them. Auxiliary render-eye access remains slot 173, now targeting RVA 0x937DA0. The entity-count accessor at 0x9F2480 still reports population, not the highest occupied index.

The final player hook retains the exact 20-byte replay, aligned native frame, final origin/angle history copies and epilogue. The clock still calls validated virtual methods; it does not read pause flags directly. The new pause method reads flags at +0x1238/+0x1239 instead of +0x1230/+0x1231, and the offline method-body check was updated to match the verified new read-only query.

Negative checks under the **new** PE fingerprints rejected the old 0x3600 eye offset, old player tail RVA and old GetDemoFile RVA. Thus merely updating the whitelist cannot pass the complete compatibility checks.

## Limits

Background/offline results establish the stated compatibility checks and regression behavior; they do not establish a new live-demo, ReShade coexistence or real FPS measurement. Earlier user confirmation of stable prop sampling and improved body clipping belongs to preserved implementations. Residual player turning/knife jitter has not received live confirmation of resolution, and this compatibility release does not claim to solve it. Automatic map collision avoidance is not implemented. Fully restart HLAE/CS2 and load one new DLL after upgrading.
